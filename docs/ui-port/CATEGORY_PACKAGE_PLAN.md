# Category package plan

Each of the following will be rebuilt as a code-only production port package that depends on this foundation:

1. Event Discovery, Creation and Scheduling
2. Authentication, Accounts and Controlled Access
3. Navigation, Workspace Structure and Pagination
4. Records, Teams and Administration
5. Form Inputs, Selection and Data Capture
6. Dialogs, Modals and Overlays
7. Actions, Menus and Operation Feedback
8. Files, Evidence and Uploads
9. Sharing, Invitations and Communications
10. Help, Error States and Notifications
11. Pricing and Commercial Selection
12. Public Website, Marketing and Social Proof
13. Appearance and Display Preferences

Every package will contain code, tests, exports and a manifest. Guidance and shared contracts will not be duplicated inside the category packages.
