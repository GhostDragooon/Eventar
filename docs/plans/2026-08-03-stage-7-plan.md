### 7.2 — `DEFERRED` item 56: organiser↔body authorisation ⟵ **the one that blocks Stage 8**
Its re-entry criterion has **fired**: `set_event_cpd_config()` is `authenticated`-executable, so an organiser can bind their own event to any active body and self-assert accreditation. The grant lock and every in-function gate hold — this is **not** a security regression — but nothing models *which organisation may claim which body*, and that is the first question a body's security review asks.

Not a fix to guess at: it is a registry-relationship decision. Minimum viable shape for the pilot is an explicit allow-list join (organisation × accrediting_body, status) checked inside `set_event_cpd_config`, with the full approval workflow deferred to Stage 10. **Cannot ship a real accredited event without it.**

### 7.3 — Roster licence eligibility
Surface per-registrant eligibility on the check-in roster so an operator can see that a lapsed licence means the credit will silently never post. **It is not a free RLS read** — `registrations` has no `user_id`, `public.users` has no email, and organiser staff have no read policy on `practitioner_licences`. Needs a `SECURITY DEFINER` function mirroring `award_attendance_credit`'s identity chain (`lower(trim(email))` → `auth.users` → licence), returning `registration_id` + an eligibility enum and **no PII**. Good standing is `status = 'verified'`, never `'active'`.

### 7.4 — CPD config at event creation
Reuse `set_event_cpd_config()` from the create action. **Do not** widen `create_event_with_blocks`' column whitelist — those columns were locked in July precisely to stop an organiser writing them directly. Depends on 7.2 (the authorisation model) landing first, or it ships the same self-assertion twice.

Fix the guard at source now that 7.1 makes `checkin_modes` real.
- **Item 55** — the global `credit_ledger` advisory lock has no acquisition timeout. Add `SET LOCAL lock_timeout` and degrade to `skip` rather than block the scanner. Cheap; per-body chains remain the real fix at scale (Stage 10).
