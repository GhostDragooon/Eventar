Their refusal copy reuses the ownership sentence ("Only the organiser who created this event, or an organiser admin, can change it. Unselect it, or ask an organiser admin."), which is wrong for an auditor/body_admin: no selection would ever work for them.

MINOR 6. On a draft /details page the Registration card shows an enabled "Edit event" link ("Publish this event to open registration.") to auditor and body_admin, under a page header that says "Your role can't change events. Ask an organiser admin." The link lands on the read-only page.

NIT 3. The nav-rail group label "ADMIN" shows above Settings for member, body_admin and auditor (Settings is personal there).
NIT 4. Member's non-creator desk: mark_attended through REST returns HTTP 200 result "not_recognised" (not a 403) because RLS hides the registration. Safe (nothing written) and leaks nothing, but the message "not recognised" is the only signal.
