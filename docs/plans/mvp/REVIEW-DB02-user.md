## Answers to the brief's questions (live)

- Clear why the controls are off, and when they work? Why: yes, top of the controls ("has not opened yet", "is closed. This event has ended"). When: "60 minutes before" yes, clock time no (U10). Per row: no (U1).
- Better than before? Yes: nothing is offered that the server will refuse, and the three desks showed the right note (not open, ended) or none (live).
- Placement, phone width, contrast, announcement: sits above the two buttons, two lines at 375 px, no overflow; contrast measured 7.3:1 light (`#565656` on white, computed from tokens and rendered `rgb(86,86,86)`) and 8.13:1 dark (`rgb(166,166,166)` on `rgb(10,10,10)`, computed from the rendered colours); `role="status"` present, announcement untested (U3).
- Disabled vs broken page: not confusable, except that "+ Walk-in" stays bright (U2) and Enter code nearly vanishes (U8).
- "+ Walk-in" when closed: opens a dialog with different wording and live inputs over a dead submit (U2).
- Useful when closed: yes. Roster, All / Checked in / Pending filters and search by name or code work. Typing a code in search filters only, it does not check anyone in.
- Wrong things tried: pressed the disabled Scan badge (nothing happens, no dialog, no message); typed a code in search (U1); opened walk-in at the not-open event (U2). Not done: pressing a disabled row button with a real click (pointer-events none, same as Scan badge).

## Worked well

- The window opened by itself, without a reload, within the 30 s tick; controls enabled, note gone, scoreboard to LIVE (U5).
- One derivation (`computeLifecycle` / `checkInGateMessage`) drives buttons, row titles and the scoreboard, so they cannot disagree. The ended desk showed "Check-in is closed. This event has ended." on the note and the row titles.
- No em-dash in the new strings; the note is plain, specific and readable in both schemes.
- No horizontal overflow at 375 px; roster and search stay usable when closed.
- Attendee pass states are right per time: early (no button, tells when), live (Confirm I'm here), ended (closed, see staff).
