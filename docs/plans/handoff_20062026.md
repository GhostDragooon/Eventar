## Product-flow decisions locked (need backend work)

These were previously unspecified and got decided in-session. **Full detail in the session log; summary here:**

### Check-in — two paths, organizer toggle, staff-default
`events.checkin_modes` jsonb `{ staff, self_serve }`, default `{ staff:true, self_serve:false }`. Staff-driven (TC) is default so presence is verified. Self-serve (CI self-tap) is opt-in. When self-serve off, `/checkin/confirm?code=` shows a "see reception" fallback, not a silent check-in. Toggle is structural (frozen at publish).

### Event Manager lock policy — cosmetic vs structural
Pre-publish = full autonomy. Post-publish (= registration opens) structural fields **lock** (`ti-lock` + tooltip); cosmetic fields stay editable, silently propagated. Rationale: avoids email-bomb + false-advertising. No structural edits once people have registered.

### Registration window — explicit open + close
Organizer picks **both** an open date and a close date (not "opens on publish"). Needs a **new `registration_open_at` column** (today only `registration_close_at` exists). Day-counter shows calendar-days + working-days between them.

### Capacity — optional, blank = unlimited (no hard cap)
Capacity is now optional. Blank = unlimited; the old "up to 200" venue ceiling is **not enforced** when blank. Registration then only closes at the close date.

### Working-days counter — weekends + HK public holidays
The registration day-counter excludes Sat/Sun **and** HK public holidays. **Open question:** which region's holidays for non-HK venues (derive from venue country?). Punted to build.

### Delete events — on every card, Deleted bucket
Per user call, Edit + Delete on every dashboard card (confirm-guarded). Deleted events go to a recoverable **Deleted** filter (distinct from Cancelled).

### Numbers font — all Geist Sans
User dropped Geist Mono from numbers entirely (dates/times/counts/deltas all Geist Sans). **This OVERRIDES the Design Language "mono for numerical data" rule** — applied on DB; should propagate to other surfaces on their next pass. The mono rule is now contested; treat sans as the newer decision.
