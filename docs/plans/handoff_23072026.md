## Friction worth knowing about (so it isn't repeated)

- **Two corrective rounds on "global shell."** First pass answered the architecture review as a written memo with no visual change (wrong — Ivan: "you said nothing... give me the same shit again"). Second pass built the shell but duplicated chrome per page instead of rendering it once (wrong — Ivan: "global ones should be global"). Third pass — one shell per context, sidebar/nav navigates in place, page content swaps — is what stuck. **Read this as: when asked for a structural/architectural change, change the structure, and render it once.**
- **Screenshot-driven fixes on option D found 3 real bugs**, not just taste: `.herozone{overflow:hidden}` was clipping the overlapping product frame in *every* aesthetic variant (not just D); landing CTAs were boxy rectangles inside a pill nav; and a section-clearance CSS selector (`:first-of-type`) was dead code that never matched anything. **Lesson: when Ivan sends a cropped/odd screenshot, don't assume it's only a framing complaint — check the actual box model.**
- **`[hidden]` was being defeated by explicit `display` values** on toggled elements (both audience variants rendered simultaneously under the hood) — fixed globally with `[hidden]{display:none!important}`. Any new toggle-style element in this artifact is safe by default now; don't reintroduce per-element `display` overrides on `[data-aud-el]`/similar without checking this rule still wins.
- **uiverse.io added to the toolbox** (Ivan's instruction) but the site 403s `WebFetch` — pattern must be reproduced from knowledge/inline, never linked (artifact CSP blocks external CSS anyway). Noted in memory `uiverse-ui-elements-library`.
