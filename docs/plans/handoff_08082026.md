### 5.3 Review mode reinstated
`lib/reviewMode.ts` + bypasses in `requireStaff`, `proxy.ts`, and `supabaseServer()`, plus a pinned banner (`components/dev/ReviewBanner.tsx`). Enabled by `dev-local.sh`.

**It cannot follow the code anywhere.** `isReviewMode()` checks `NODE_ENV === 'production'` **first and unconditionally**, and requires the exact string `'true'` — no truthiness. **9 tests on the guard alone**, including that it refuses to engage in production *with the flag set*. **Why the data-layer bypass is safe now and was not before:** the PKCE bug that got the old one stripped happened because `sendMagicLink` used `supabaseServer()`. Auth flows now call `supabaseAnonServer()` explicitly, so token-minting never reaches that branch.

Viewing works everywhere; staff **mutations refuse**. That is the correct posture (Layer 3 intact) and it is why the demo fixture was populated by direct SQL.
