### 3. Popped registration code (RC-B Strong, sunny amber variant)
**Light variant (used in emails):**

**Dark variant (used in CI, PR):**

Label is shifted `position: relative; top: -10px` (user-requested, EM-5/CI-5 specific). The intentional warm-palette break on an otherwise cool page is the design move — same emotional weight as a sticky highlight.

### 4. Spacing rhythm — single CSS variable
```css
:root { --gap: 24px; --gap-sm: 12px; }
.container {
  display: flex;
  flex-direction: column;
  gap: var(--gap);          /* between major elements */
  padding: var(--gap);       /* matches between-item rhythm at edges */
}
.hero-title, .body-text, .small-meta { margin: 0; }  /* reset to let gap own spacing */
```

Two-tier: `--gap: 24px` for major-element rhythm, `--gap-sm: 12px` for within-section grouping (e.g., tiles inside a lifecycle band). Briefly experimented with 28px and 48px; both reverted to 24px.

### 5. "By Eventar" footer (all pages)

- No platform topbar — brand moves to bottom-of-page credit
- Applies to all 12 surfaces (public + staff)
- The pattern that drives this: content-first, platform credits attendee-facing

### 6. Event meta — 2-column grid (locked)

## Mistakes logged (do not repeat)

| Code | Mistake | Fix | Rule |
|---|---|---|---|
| M1 | Double-spacing via `gap` + `line-height` on text elements | Use ONE authority for spacing-between-text. `gap: 0` + line-height OR `margin` + gap: 0. | For adjacent text, never stack `gap` and `line-height` leading. |
| M2 | Mixing fonts within "By Eventar" attribution | Uniform font, single weight, single color | Footer/attribution areas: uniformity > expressive type. |
| M3 | Top-bar branding on attendee pages | Brand → bottom centered credit footer | Attendee-facing surfaces: content > platform branding. |
| M4 | Capacity stuffed onto same line as date/time/venue | 2-row event meta (now 3-row grid) | Event meta sorts into where/when/status — separate slots. |
| M5 | 80KB single-file audit (preview panel choked) | One surface per file at ~8KB, same URL `preview.html`, overwrite on advance | Iframe previews prefer many small files. |
| M6 | Email designed with modern CSS without flagging client limits | Mockup uses flex `gap`; production needs tables + `margin: 0 0 8px` per element | Email surfaces = separate target platform. |
| M7 | Padding-top change moves the code AND the label | Use `position: relative; top: -10px` on the label only when code position must stay fixed | When user says "without touching anything else," surgical means touching ONE property on ONE element. |

Full mistake log + reasoning lives in `docs/plans/eventar-design-patterns.md`.
