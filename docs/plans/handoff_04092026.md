### `058ff8c` — Licence declare/list UI (item 1, F4 unblocker)

Without this UI, no real signup could clear F4 of the F1-F5 credit
gate. The RPCs (`declare_licence`, `verify_licence`, ...) landed in
Sprints 2/3; only the form-and-list surface was missing.

- **`listMyLicences()`** reads under caller's session via
  `practitioner_licences_self_read` RLS; app-joins body short_name
  from `accrediting_bodies` in one round-trip.
- **`declareMyLicence(raw)`** — Zod first (`licenceDeclareSchema`),
  per-user rate limit (30/60s), then RPC. Error mapping:
  `23505` → `already_declared`, `P0002 …"not active"` →
  `body_inactive`, `P0002` else → `body_not_found`, `42501` →
  `not_authorized`, else `db_error`. **Fail-visibly guard**: RPC
  success with no licence id returns `db_error` (audit event is
  durable; next `listMyLicences` reconciles).
- **UI** — new `<SectionCard icon="verified" title="Licences">` between
  Role and Speaker preferences. Empty-state hint, list of existing
  licences with body short_name / number / status pill / Primary badge
  (suppressed for lone licences per user-lens CONFUSING). Declare form
  with body picker + licence number + Declare button. Optimistic append
  on success — `is_primary: false` ALWAYS because `declare_licence`
  never grants true (dev-lens CRITICAL fix).
- **F3+F4 combined readiness banner** — the pre-existing F3-only
  banner now composes F3 (workplace + position + profession) AND F4
  (≥1 non-terminal licence). Green ONLY when both are true; otherwise
  a bulleted checklist naming each remaining gate. Closes the
  user-lens BLOCKER (pre-fix banner would go green from just F3 and
  lie about CPD readiness).
- **`LicenceStatusPill`** — five statuses, three visual treatments
  (active → tertiary-container, verified → success-container, revoked
  → error-container, lapsed/superseded → muted italic). Aria-label
  carries "Status: <name>" prefix for screen readers.
- **AccountClient entry copy** — "Edit professional profile" → "Edit
  professional profile & licences" (user-lens IMPORTANT — first-time
  HKCP users had no way to guess licences lived on this page).

11 tests covering empty state, list render, happy declare, three error
branches, Primary badge suppression/appearance, aria-label, and three
F3+F4 combined-banner scenarios.

Deferred per Ponytail: primary toggle, supersede/renew, track/
cycle-anchor inputs, verify-side UI. All optional at the RPC layer.
