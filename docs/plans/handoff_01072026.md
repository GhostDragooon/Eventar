**Design decisions taken this session (were open forks):**
- **QR delivery = CID inline attachment** (not data-URI, which Gmail strips; not hosted-URL). The `sendEmail` facade gained an optional `attachments` field for this.
- **Trigger = actions + minimal staff buttons** (so the loop is click-testable on localhost now); the redesigned Wave-5 surface restyles them later.
- **Idempotency = insert-log-first + partial unique index** `(event_id, registration_id, purpose) where registration_id is not null` — the vault `Cron + Email.md` locked pattern. These actions are the exact units Phase 9's pg_cron jobs will call.
